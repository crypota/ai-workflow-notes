# Reference-first visual workflow

Use when a supplied character or design must remain recognizable.

1. **Collect the source.** Save the original reference, provenance and usage
   constraints. Do not label generated imagery as an original source.
2. **Write an identity checklist.** Record silhouette, proportions, anatomy,
   colors, accessories, viewpoint, canvas size and exact alignment requirements.
3. **Mark unknown geometry.** List regions hidden by clothing, props or the
   viewpoint. Request another view when that geometry matters. A reconstruction
   from incomplete views remains a hypothesis.
4. **Freeze the intended change.** Specify exactly which region may change and
   which features must remain fixed. Save the unmodified reference separately.
5. **Generate one reviewable candidate.** Keep the prompt, supplied references
   and output. Split independent edits if they make errors easier to locate.
6. **Audit against the source.** Check every identity requirement, then inspect
   output dimensions, transparency and overlay alignment if layers must match.
7. **Accept or reject explicitly.** A plausible image can still fail an exact
   reference task. Record the mismatch before another attempt.

| --- | --- | --- | --- |
| <region> | <reference/view> | <change or none> | <uncertainty> |

Save original outputs before cleanup. A retouched final image should not be
presented as the untouched output of a model.
