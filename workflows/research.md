# Evidence-led research workflow

1. State a concrete question and the decision it informs. Set the relevant date
   range and define what would count as sufficient evidence.
2. Break the question into individual, checkable claims. Prefer original
   documentation, source data and direct statements over repeated summaries.
3. Record each claim in the [evidence log](../templates/evidence-log.md). Check
   that the cited passage supports that exact claim, including units and scope.
4. Separate observation, inference and hypothesis. Preserve conflicts instead
   of smoothing them into a more confident story.
5. Recalculate important numbers where possible. Record formulas, inputs and
   commands so someone else can inspect the calculation.
6. Write the conclusion at the strength the evidence permits. State missing
   data and which assumptions would change the decision.
7. Before publishing time-sensitive claims, recheck the underlying source and
   record the retrieval time. A previously correct answer may become stale.

Completion means the stated question is answered with traceable support, or the
remaining evidence gap is clear. More collected links alone do not mean completion.
